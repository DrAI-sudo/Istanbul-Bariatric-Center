### 10.6 Fix the sitemap `lastmod`

In whatever script generates `sitemap.xml`, replace static dates with the file's real last-modified timestamp:

```js
// pseudo-code — adapt to your Replit build
const lastmod = new Date(fs.statSync(routeFile).mtime).toISOString().slice(0,10);
```

Then either regenerate on every deploy or run daily via a cron.
